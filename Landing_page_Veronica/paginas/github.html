UX na prática: o que apliquei neste site

Estou estudando Experiência e Interface com o Usuário. Nesta landing page, busquei aplicar princípios de usabilidade para tornar a navegação mais clara.

  • Consistência: botões, cores e menus seguem um padrão.
  • Reconhecimento: o menu destaca a página atual e os links têm nomes descritivos.
  • Controle do usuário: páginas explicativas oferecem um caminho de volta.
  • Prevenção de erros: o formulário utiliza validação de campos obrigatórios.
  • Visibilidade do estado: o formulário informa que os dados foram validados, mas não enviados.
  • Estética minimalista: cards, espaçamento e azul-bebê ajudam a organizar o conteúdo.

Essas são aplicações práticas de parte das dez heurísticas de Nielsen, não uma certificação de conformidade ou uma avaliação formal de usabilidade.
